Overview

Introduction

Devfolio is a lightweight developer portfolio project designed to be forked, customized, and deployed.

It provides a clean foundation for showcasing your profile, projects, skills, social links, and other developer information without starting from scratch.

What Devfolio is

A customizable portfolio starter that you can turn into your own personal website or expand into a complete portfolio platform.

01

Minimal

A dark, developer-focused interface with a clean visual system.

02

Responsive

Designed to work across desktop, tablet, and mobile screens.

03

Customizable

Modify the data, components, styling, and structure to fit your needs.

04

Open source

Fork the repository and build your own version on top of the existing foundation.

Installation

Getting started

Get Devfolio running locally in a few steps.

Requirements

Before starting, make sure you have Node.js 18.18+ installed, along with npm and Git.

Clone the repository

git clone https://github.com/logicnestxvoidlure/devfolio.git
cd devfolio

Install dependencies

npm install

Start the development server

npm run dev

Once the server starts, open http://localhost:3000 in your browser.

Development

Development workflow

Devfolio uses Next.js with TypeScript and Tailwind CSS. The project uses the Next.js App Router.

npm run dev

Make your changes inside the application, save the file, and Next.js will update the development server automatically.

Configuration

Portfolio data

The starter portfolio currently uses demo data stored inside lib/demo-data.ts.

This is the main place to customize the example portfolio before connecting the project to a database.

Available information

Profile

Display name, username, headline, bio, avatar, and location.

Skills

Technologies, tools, and skills displayed on the portfolio.

Socials

Links to platforms such as Roblox, Discord, and GitHub.

Projects

Project titles, descriptions, roles, images, tags, links, and featured status.

Example

export const demoPortfolio: Portfolio = {
  username: "yourusername",
  displayName: "Your Name",
  headline: "Roblox Developer",
  bio: "I create Roblox experiences and systems.",
  avatar: "YOUR_AVATAR_URL",
  skills: [
    "Luau",
    "Roblox Studio",
    "UI/UX",
    "Building"
  ],
  socials: {
    roblox: "YOUR_ROBLOX_URL",
    discord: "YOUR_DISCORD_URL",
    github: "YOUR_GITHUB_URL"
  },
  projects: [
    {
      id: "1",
      title: "My Roblox Game",
      description: "A Roblox project I worked on.",
      role: "Scripter",
      image: "YOUR_IMAGE_URL",
      tags: ["Luau", "Roblox"],
      link: "YOUR_GAME_URL",
      featured: true
    }
  ]
};
Content

Projects

Projects are part of the portfolio data structure. Each project can contain information used by the project card component.

Property Description
idUnique identifier for the project.
titleName displayed for the project.
descriptionShort explanation of the project.
roleYour role on the project.
imageProject preview image.
tagsTechnologies or categories.
linkExternal project URL.
featuredWhether the project is featured.
Navigation

Routes

Devfolio currently includes three main application routes.

Route Purpose
/Demo public portfolio.
/dashboardStarter portfolio editor.
/u/[username]Public username-based portfolio.

Public profiles

A username-based portfolio can be accessed through the dynamic route.

/u/logicnest

The current implementation uses demo data. A future database implementation can use the username to retrieve the correct portfolio.

Customization

Styling

Global styling is located inside app/globals.css.

You can customize colors, typography, spacing, animations, backgrounds, cards, navigation, portfolio sections, and responsive behavior.

Tip

Start by changing the global design tokens and then modify individual components when you need more specific changes.

UI

Components

The main reusable UI components are located inside the components/ directory.

navbar.tsx

Handles the main portfolio navigation.

portfolio.tsx

Provides the main portfolio presentation.

project-card.tsx

Displays individual portfolio projects.

Architecture

Project structure

The repository keeps application routes, reusable components, and data definitions separated.

devfolio/ │ ├── app/ │ ├── dashboard/ │ │ └── page.tsx │ ├── u/ │ │ └── [username]/ │ │ └── page.tsx │ ├── globals.css │ ├── layout.tsx │ ├── not-found.tsx │ └── page.tsx ├── components/ │ ├── navbar.tsx │ ├── portfolio.tsx │ └── project-card.tsx ├── lib/ │ ├── demo-data.ts │ └── types.ts ├── .env.example ├── eslint.config.mjs ├── next.config.ts ├── package.json └── tsconfig.json
Production

Deployment

Devfolio can be deployed to platforms such as Vercel.

Build the project

npm run build

Start production

npm start

Vercel

Fork the repository, import the fork into Vercel, configure any required environment variables, and deploy the project.

Configuration

Environment variables

If your version requires environment variables, copy .env.example to .env.local and add the required values.

Keep secrets private

Never commit API keys, passwords, tokens, or other private credentials to GitHub.
